## 📋 Project Overview

A complete **CI/CD pipeline** that automatically builds Docker images and pushes them to Docker Hub using **GitHub Actions**. Every code push triggers an automated build, test, and deployment process.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| ✅ **Automated Builds** | Triggered on every push to main branch |
| 🔧 **Docker Integration** | Multi-stage builds with 45.3MB optimized images |
| 🔒 **Secure Authentication** | GitHub Secrets for Docker Hub credentials |
| 🐍 **Python Flask App** | Simple web application for testing |
| 🛡️ **Security Ready** | Trivy vulnerability scanning integration |
| 📦 **Registry Push** | Automatic push to Docker Hub with latest & commit SHA tags |
